# تطبيق المريض (Flutter) — المساعد الطبي الذكي

⚠️ **هذا الكود لم يُشغَّل أو يُختبَر فعلياً بواسطتي** — بيئتي لا تملك Flutter/Dart مثبَّتاً ولا يمكنني تثبيته (SDK محجوب شبكياً هنا). الكود مكتوب يدوياً حسب خبرتي بـ Flutter وهو نمط قياسي صحيح، لكنه **يحتاج منك أول تشغيل واختبار فعلي**.

## 🚀 التشغيل

### المتطلبات
- Flutter SDK مثبَّت ([flutter.dev](https://flutter.dev)) — تحقق: `flutter doctor`
- الباك-إند يعمل (`../backend`)

### الخطوات
```bash
flutter pub get
```

**مهم جداً:** عدّل رابط الباك-إند في `lib/config.dart` حسب جهازك:
- **محاكي أندرويد (Android Emulator)**: `10.0.2.2:3000` (القيمة الافتراضية الحالية) ✅
- **محاكي iOS (iOS Simulator)**: `localhost:3000`
- **جهاز حقيقي على نفس الشبكة**: عنوان IP جهاز الكمبيوتر (مثال: `192.168.1.5:3000`)

يمكنك أيضاً تمريره وقت التشغيل بدل تعديل الكود:
```bash
flutter run --dart-define=API_BASE_URL=http://192.168.1.5:3000
```

## 📁 الهيكل
```
lib/
├── main.dart                  → نقطة الدخول
├── config.dart                → رابط الباك-إند
├── theme/app_theme.dart       → نفس ألوان الويب بالضبط
├── services/
│   ├── api_client.dart        → عميل HTTP موحّد
│   └── session_service.dart   → حفظ الجلسة محلياً
├── models/models.dart         → نماذج البيانات
└── screens/
    ├── auth/                  → تسجيل دخول + حساب جديد
    ├── home/                  → الشاشة الرئيسية (الموعد القادم + وصول سريع)
    ├── chat/                  → المساعد الصحي (شات AI)
    └── records/                → وصفاتي + نتائج تحاليلي
```

## ✅ ما بُني (تطبيق المريض فقط، أول نسخة)
- تسجيل دخول / حساب جديد (يربط تلقائياً بملف المريض إن كان الطبيب سجّله سابقاً بنفس الهاتف)
- الشاشة الرئيسية: الموعد القادم + وصول سريع
- شات المساعد الصحي (مربوط بـ `/ai/chat` مع نفس ضوابط الأمان الموجودة بالباك-إند)
- عرض الوصفات الطبية
- عرض نتائج التحاليل (مع تمييز أحمر للقيم غير الطبيعية)

## ❌ ما لم يُبنَ بعد
- **تطبيق الطبيب على الموبايل** (هذا تطبيق المريض فقط — الطبيب يستخدم الويب حالياً)
- مسح QR بالكاميرا (يحتاج حزمة `mobile_scanner` أو مشابه — لم أضفها لتقليل التبعيات غير المُختبَرة)
- إشعارات Push حقيقية (تذكير أدوية/مواعيد)
- شاشة عرض/تعديل الملف الشخصي الكامل للمريض
- شاشة "كل مواعيدي" (الزر موجود، الشاشة لم تُبنَ بعد)
- أيقونة التطبيق ورقم إصدار Play Store/App Store

شغّل `flutter analyze` وأرسل لي أي خطأ يظهر — هذا أهم اختبار أول، لأنني لم أتمكن من فعله بنفسي.
