# Medical Assistant API — الباك-إند

باك-إند تطبيق المساعد الطبي الذكي (المرحلة 1: تسجيل المرضى + QR + الملف الطبي + المواعيد).

بُني بـ **NestJS + Prisma + PostgreSQL**، مع مصادقة JWT ونظام صلاحيات (RBAC: طبيب/سكرتير/مريض/أدمن).

## 🚀 التشغيل المحلي

### المتطلبات
- Node.js 18+
- PostgreSQL 14+ (يمكن تشغيله محلياً أو عبر Docker)

### الخطوات

```bash
# 1. تثبيت الحزم (تم بالفعل إذا استلمت المشروع جاهزاً)
npm install

# 2. إعداد متغيرات البيئة
cp .env.example .env
# عدّل DATABASE_URL في .env ليطابق إعدادات PostgreSQL عندك

# 3. توليد Prisma Client
npx prisma generate

# 4. إنشاء الجداول في قاعدة البيانات
npx prisma migrate dev --name init

# 5. (اختياري) إدخال بيانات تجريبية للاختبار السريع
npx ts-node prisma/seed.ts

# 6. تشغيل السيرفر في وضع التطوير
npm run start:dev
```

السيرفر يعمل على: `http://localhost:3000`
توثيق API تفاعلي (Swagger): `http://localhost:3000/docs`

### تشغيل PostgreSQL بسرعة عبر Docker (إن لم يكن مثبتاً)
```bash
docker run --name medical-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=medical_assistant -p 5432:5432 -d postgres:16
```

## 📁 هيكل المشروع

```
src/
  auth/              → تسجيل الدخول والتسجيل + JWT
  patients/          → تسجيل المرضى + توليد QR
  qr/                → مسح QR (endpoint عام: جدول الأدوية + الموعد القادم)
  appointments/       → المواعيد + مواعيد اليوم (لوحة تحكم الطبيب)
  medical-reports/   → التقارير الطبية
  common/            → Guards, Decorators (RBAC)
  prisma/            → اتصال قاعدة البيانات
prisma/
  schema.prisma      → مخطط قاعدة البيانات الكامل (كل الوحدات، بما فيها المراحل القادمة)
  seed.ts            → بيانات تجريبية
```

## 📌 ملاحظات أمان مهمة قبل الإنتاج
- استبدل `JWT_SECRET` بمفتاح عشوائي طويل.
- فعّل rate-limiting على `/qr/:qrCodeId` (endpoint عام بدون مصادقة).
- فعّل تشفير TLS (HTTPS) في الإنتاج.
- أضف Audit Log فعلياً عند كل عملية اطلاع/تعديل على ملف مريض (الجدول موجود في schema.prisma).
